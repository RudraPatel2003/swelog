## Privacy First

Swelog runs entirely on your computer. There is no account required, and
there is no swelog server to send anything to. The only time data leaves your machine
is if you opt-in to an integration or AI summarization.

See the [Privacy Policy](/legal/privacy/) for what the tool stores, what it sends over
the network, and what happens to the notes you hand to a language model. See the
[Terms of Service](/legal/terms/) for the terms you agree to by using it.
