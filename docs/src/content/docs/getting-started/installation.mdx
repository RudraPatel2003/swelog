---
title: Installation
description:
  Install the swelog CLI, confirm it is available on your PATH, and keep it up to
  date.
---

Install the CLI with npm:

```sh
npm install -g swelog-cli
```

Confirm the installation:

```sh
swelog --help
```

## Requirements

- **Obsidian** — swelog writes all of its files into an Obsidian vault.
- **Node.js 22 or newer** — required by the npm package installer.

## Optional

- **A summarization provider** — [Ollama](/summarization/providers/) running
  locally, or an API key for OpenAI, OpenRouter, or Anthropic. see [`swelog summarize`](/summarization/) for more information.
- **Integration credentials** — a GitHub token, or a Linear or Google Calendar
  authorization. see [`swelog fetch`](/integrations/) for more information.

Once installed, continue to the [Quick Start](/getting-started/quick-start/).
