## Requirements

- **Obsidian** — swelog writes all of its files into an Obsidian vault.
- **Node.js 22 or newer** — required by the npm package installer.

## Installation

Install the CLI with npm:

```sh
npm install -g swelog-cli
```

:::note
You have to use `npm`, not any other package manager, or it won't install the binary correctly
:::

Confirm the installation:

```sh
swelog --help
```

Once installed, continue to the [Quick Start](/getting-started/quick-start/).

## WSL-specific configuration

WSL ships without a Secret Service provider, so [Integrations](/integrations/) fail until you install one.

Install the keyring and its manager:

```sh
sudo apt install gnome-keyring seahorse
```

Open the keyring manager:

```sh
seahorse
```

Create a new password keyring named `login`. Any password works, but your WSL
user password is the easiest to remember.
