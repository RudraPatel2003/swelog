---
title: Quick Start
description: Configure swelog, create your vault files, and file your first day.
---

## 1. Create the configuration file

```sh
swelog init
```

This creates `swelog/swelog.json` inside your operating system's configuration
directory. Run `swelog config` at any time to display the exact path.

## 2. Configure your Obsidian vault

Open `swelog.json` and set `obsidianVaultPath` to the absolute path of your
vault. That is the only field you have to fill in unless you want to change the default storage location.

```json
{
  "obsidianVaultPath": "/absolute/path/to/your/vault",
  "swelogFolderName": "swelog",
  "workFileName": "WORK.md",
  "dailyLogFolderName": "Daily",
  "weeklyLogFolderName": "Weekly"
}
```

## 3. Create the vault files

```sh
swelog setup
```

Swelog creates the work file plus the daily and weekly log directories under
`<obsidianVaultPath>/<swelogFolderName>`.

## 4. Write today's notes

Open `WORK.md` in Obsidian and write down your priorities for the day under `## Priorities` and what you did under `## Log`.

## 5. Log the day

```sh
swelog log
```

This stores your notes into the daily log and resets your work file. Use the `--keep` flag if you want to leave your work file alone.
