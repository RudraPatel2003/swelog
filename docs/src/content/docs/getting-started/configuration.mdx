---
title: Configuration
description: Every field in swelog.json and what it controls.
---

Swelog stores its configuration in `swelog/swelog.json` inside your operating
system's configuration directory. All generated files and directories live
inside `<obsidianVaultPath>/<swelogFolderName>`.

To read a config file from somewhere else, pass `--config <PATH>` to any
command or set the `SWELOG_CONFIG_FILE` environment variable. The flag takes
precedence over the environment variable.

```sh
swelog --config ~/work/swelog.json log
```

## Fields

| Field                 | Required | Description                                                                                                                    |
| --------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `obsidianVaultPath`   | Yes      | Absolute path to the Obsidian vault.                                                                                           |
| `swelogFolderName`    | Yes      | Folder created inside the vault for swelog files.                                                                              |
| `workFileName`        | Yes      | Markdown file used to collect the current day's raw notes.                                                                     |
| `dailyLogFolderName`  | Yes      | Directory containing generated daily logs.                                                                                     |
| `weeklyLogFolderName` | Yes      | Directory containing generated weekly logs.                                                                                    |
| `llm`                 | No       | The LLM provider you plan to use for summarization. See [supported providers](/summarization/providers/) for more information. |
| `llmModel`            | No       | The LLM model used for summarization. See [supported providers](/summarization/providers/) for more information.               |
| `linearUsername`      | No       | Exact Linear assignee name used by `swelog fetch linear`.                                                                      |

## View the current configuration

Display the current configuration and its location:

```sh
swelog config
```
