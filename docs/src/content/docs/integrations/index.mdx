Integrations are optional. Swelog works entirely on the notes you write
yourself, and every command below is something you opt into when you want the
day's log to include activity you would otherwise retype by hand.

## How they fit into the work file

The default work file contains only `## Focus` and `## Log`. Integration
sections are created lazily, the first time you fetch that integration's
activity, and each one is owned by Swelog from then on:

```sh
swelog fetch github
swelog fetch linear
```

Both commands accept `--date MM-DD-YYYY` to record a previous day, and
`--yesterday` as a shortcut for the most common one. See
[Backfilling a Missed Day](/guides/backfilling/).

:::caution[Integration sections are generated data]
Swelog finds each integration's section by its heading, so `## GitHub` and
`## Linear` are replaced wholesale by every fetch. Renaming a heading makes the
next fetch write a fresh section under the original name. Your own notes belong
in `## Focus` and `## Log`.
:::

## Credentials

Each integration asks for its credential the first time you use it and stores it
in your operating system's credential store, never in `swelog.json`. See
[Authentication](/reference/authentication/) for how to inspect and clear them.
