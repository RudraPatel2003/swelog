---
title: Providers and Models
description: Configure Ollama, OpenAI, OpenRouter, or Anthropic as your summarization provider.
---

| Provider   | `llm`        | Example `llmModel`          | Setup                                                      | Authentication                 | Notes                                                  |
| ---------- | ------------ | --------------------------- | ---------------------------------------------------------- | ------------------------------ | ------------------------------------------------------ |
| Ollama     | `ollama`     | `llama3.2`                  | Install Ollama, pull the model, and run the local service. | None                           | Swelog connects to Ollama at `localhost:11434`.        |
| OpenAI     | `openAi`     | `gpt-5.4-mini`              | Select an OpenAI model supported by the Responses API.     | API key, prompted on first use | The model value is sent directly to OpenAI.            |
| OpenRouter | `openRouter` | `anthropic/claude-sonnet-5` | Pick any model from the OpenRouter catalog.                | API key, prompted on first use | Any model provider that OpenRouter supports will work. |
| Anthropic  | `anthropic`  | `claude-opus-5`             | Select a Claude model available on your Anthropic account. | API key, prompted on first use | The model value is sent directly to Anthropic.         |

Model names are examples, not a fixed allowlist. Set `llmModel` to a model that
is installed locally or available from the selected provider.

## Ollama

1. Install and start Ollama.
2. Pull the configured model:

   ```sh
   ollama pull llama3.2
   ```

3. Configure swelog:

   ```json
   {
     "llm": "ollama",
     "llmModel": "llama3.2"
   }
   ```

4. Run `swelog summarize`. Ensure Ollama remains available at `localhost:11434`
   while the command runs.

## OpenAI

1. Configure the provider and model:

   ```json
   {
     "llm": "openAi",
     "llmModel": "gpt-5.4-mini"
   }
   ```

2. Run `swelog summarize`. The first run asks for your
   [OpenAI API key](https://platform.openai.com/api-keys) and stores it in your
   operating system keyring.

## OpenRouter

1. Configure the provider and any model from the
   [OpenRouter catalog](https://openrouter.ai/models), using the
   `provider/model-slug` identifier OpenRouter lists for it:

   ```json
   {
     "llm": "openRouter",
     "llmModel": "anthropic/claude-sonnet-5"
   }
   ```

2. Run `swelog summarize`. The first run asks for your
   [OpenRouter API key](https://openrouter.ai/keys) and stores it in your
   operating system keyring.

## Anthropic

1. Configure the provider and model:

   ```json
   {
     "llm": "anthropic",
     "llmModel": "claude-opus-5"
   }
   ```

2. Run `swelog summarize`. The first run asks for your
   [Anthropic API key](https://console.anthropic.com/settings/keys) and stores
   it in your operating system keyring.
