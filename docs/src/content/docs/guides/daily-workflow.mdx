---
title: Daily Workflow
description: The day-to-day loop of capturing notes and filing them into a daily log.
---

1. Write notes in `WORK.md` as the day goes under the `## Log` heading in Obsidian.

2. Optionally fetch activity from GitHub, Google Calendar, or Linear:

   ```sh
   swelog fetch github
   swelog fetch google-calendar
   swelog fetch linear
   ```

3. Review and edit `WORK.md`. Integration sections are created only after the
   corresponding integration is used.

4. File the day:

   ```sh
   swelog log
   ```

   This writes `Daily/MM-DD-YYYY.md` and resets `WORK.md`. Pass `--keep` to leave `WORK.md` alone.

## Want a written summary instead?

`swelog summarize` does the same job, but sends your notes to a language model
first and writes back a summary with your raw notes preserved underneath. It is
opt-in and needs `llm` and `llmModel` in your config. See
[Summarization](/summarization/).

Weekly logs are summaries by nature, so they live there too:
`swelog summarize week` rolls up the daily logs `swelog log` produced.
