---
title: Daily Workflow
description: The day-to-day loop of capturing notes and filing them into a daily log.
---

1. Write your priority for the day under `## Priorities` and what you did under `## Log` in `WORK.md`.

2. Optionally fetch activity from external sources:

   ```sh
   swelog fetch github
   swelog fetch google-calendar
   swelog fetch linear
   ```

3. Review and edit `WORK.md`.

4. Log the day:

   ```sh
   swelog log
   ```

## Summarization

`swelog summarize` also logs the day, but sends your notes to a language model
first and writes back a summary with your raw notes preserved underneath.
See [Summarization](/summarization/) for more information.
