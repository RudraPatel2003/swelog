## Undoing a command

When you run `swelog log`, `swelog summarize`, or `swelog summarize day`, it clears your work file (unless you use `--keep`) and writes a daily log. Run `swelog undo` to delete that daily log and return your work file to what it was before.

`swelog reset` also clears your work file. Run `swelog undo` to bring it back.
